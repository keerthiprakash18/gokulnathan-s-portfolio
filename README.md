
Then open `http://localhost:4173`.

## Deployment

This is a static site and can be deployed directly to Vercel. Recommended repository name: `gokulnathan-s-portfolio`, branch: `main`.

If the final Vercel production URL differs from `https://gokulnathan-s-portfolio.vercel.app/`, update the canonical, Open Graph URL/image URL, `robots.txt`, and `sitemap.xml` accordingly.

## Content integrity

Personal claims, dates, scores, project descriptions, skills, links and certifications are sourced from the uploaded resume. No external profile content from the benchmark portfolio is reused.
